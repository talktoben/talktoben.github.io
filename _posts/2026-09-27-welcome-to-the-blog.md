## How to add a new post

Create a new file in `_posts/` named like `2026-10-15-fall-market-orange-county.md`, with front matter at the top:

```
---
layout: post
title: "Your Post Title Here"
---
Your post content, written in plain Markdown.
```

Jekyll picks up the date from the filename, builds the page automatically, and it'll show up on the Insights page in order — newest first. No HTML to write, no manual linking required.
